# Тайный Санта — онлайн-версия

Это приложение рассчитано на GitHub Pages + Supabase. GitHub Pages публикует сайт, а Supabase хранит данные, создаёт анонимные сессии пользователей и автоматически запускает жеребьёвку на сервере.

## Что уже предусмотрено

- участник регистрируется сам: вводит имя и желание;
- создатель задаёт число мест и лимит подарка;
- создатель выбирает администраторов из зарегистрировавшихся участников;
- после регистрации последнего участника сервер создаёт пары автоматически;
- обычный участник получает только своего получателя и его желание;
- администраторы видят все пары и желания;
- создатель не отображается для участников как особая роль;
- данные синхронизируются между устройствами через Supabase Realtime.

## Перед публикацией

1. Создайте проект в Supabase и в разделе **Authentication → Providers** включите `Anonymous sign-ins`.
2. Откройте **SQL Editor**, вставьте туда содержимое `supabase/schema.sql` и выполните его.
3. Скопируйте `config.example.js` в `config.js`, вставьте URL проекта и публичный `anon` key. Файл `config.js` можно публиковать: защита данных обеспечивается правилами доступа в базе, а не секретностью ключа.
4. Создайте репозиторий на GitHub, загрузите файлы проекта и включите GitHub Pages: **Settings → Pages → Deploy from a branch → main / root**.

Не загружайте в репозиторий `service_role` key — он даёт полный доступ к базе и должен оставаться только на сервере.
